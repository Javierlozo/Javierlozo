## Featured

### 🛡️ [llm-audit](https://github.com/Javierlozo/llm-audit)

Semgrep rule pack mapped to the OWASP Top 10 for LLM Applications (2026). Ships as an npm CLI, a Husky pre-commit hook, and a GitHub Actions workflow. Twelve rules covering LLM01 Prompt Injection, LLM02 Sensitive Information Disclosure, LLM03 Excessive Agency, LLM06 Unbounded Consumption, LLM08 Hidden Context Exposure, and LLM10 Improper Output Handling.

**Currently building:** v2, with expanded rule coverage, agentic application patterns, and MCP server misconfiguration checks.
