## Featured

### 🛡️ [llm-audit](https://github.com/Javierlozo/llm-audit)

Semgrep rule pack mapped to the OWASP Top 10 for LLM Applications (2025). Ships as an npm CLI, a Husky pre-commit hook, and a GitHub Actions workflow. Current coverage: LLM01 Prompt Injection, LLM02 Sensitive Information Disclosure, LLM05 Improper Output Handling, LLM06 Excessive Agency.

**Currently building:** v2 — expanded rule coverage, agentic application patterns, and MCP server misconfiguration checks.
